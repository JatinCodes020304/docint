# Sample outputs

These files document the API response/validation structure used by the prototype and the regression cases exercised during development.

- `invoice_receipt_example.json` — scanned receipt structure and missing-field behavior.
- `balance_sheet_example.json` — comparative balance-sheet identity.
- `profit_and_loss_example.json` — banking-style P&L values and deterministic reconciliations.
- `cash_flow_example.json` — comparative cash-flow reconciliation including cash acquired on amalgamation.
- `invalid_file_error_example.json` — controlled unsupported-file error.

For the final submission/demo, also export the **actual raw JSON** from each of the four documents processed on the deployed Railway instance and keep those files here. Do not hand-edit a captured live response.
